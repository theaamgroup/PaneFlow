## What's new

- **The Files sidebar shows git status:** Modified, added, deleted, and untracked files are colored in the tree, and a folder rolls its children's state up onto itself. Ignored paths stay out of the tree entirely.
- **A workspace with no panes offers the pane palette:** Close the last pane and the picker is already there to start the next one. Escape leaves it alone rather than emptying the window.

## Fixed

- Opening a workspace in Zed, Cursor, VS Code, Windsurf, or Finder no longer stalls the window while the editor starts, and a launch that fails now says so.
- A worktree created under `<repo>.worktrees` is recognised again after git resolves its path through a symlink.
- Expanding a folder in the Files tree refreshes the git status underneath it, so a change made while the folder was collapsed no longer shows stale colors.
- Dropdown rows and triggers in Settings use the theme's text color instead of a hardcoded one.

## Install

Download the `.dmg`, open it, drag PaneFlow to `/Applications`.
Requires macOS on Apple Silicon.
