## What's new

- **Maximize the Changes dock:** Cmd+Shift+F expands the dock over the pane grid and restores it with the same shortcut. Focus follows what you can actually see, on the way in and on the way back.
- **Files tree in the dock:** Put the file tree in the Changes dock instead of its own rail, and pick which with `files_tree_placement`.
- **Changes is a tab like any other:** The dock starts on the picker, Changes opens from the `+` menu, and every dock tab closes.
- **Workspace notification controls:** Mute or unmute a workspace and mark it read from its sidebar menu. Desktop notifications now only fire for a pane you are not looking at.
- **Per-workspace new-tab branches:** Each workspace decides which branch a new tab starts on.
- **Remembered editor controls:** Minimap and Scrollbar choices apply to every open file and survive a restart.
- **Session restore remembers more:** Unread tabs, muted workspaces, and pull-request markers come back with the window, markers showing immediately while their state refreshes behind them.
- **Readable terminal text:** `terminal.minimum_contrast` keeps low-contrast color schemes legible.
- **Smoother menus:** Menus fade into place, instantly when Reduce Motion is on.

## Faster

- **Editor opens instantly:** Large files show text right away and color in as you scroll, instead of blocking on a full parse. Highlighting now handles files up to 2 MB (1 MB Markdown).
- **Files tree off the render thread:** Scanning and filtering a large tree no longer competes with drawing the window.

## Fixed

- Pane Overview and keyboard-shortcut discovery.
- Sidebar rows sit inside the indent guide, and branch labels fit.
- A pane running one agent is counted once, not twice.
- Renaming a session renames its tab, without overwriting a name you chose yourself.
- Unread agent completions follow a pane when you move it to another workspace.
- The config file's lock is released reliably on exit.

## Install

Download the `.dmg`, open it, drag PaneFlow to `/Applications`.
Requires macOS on Apple Silicon.
