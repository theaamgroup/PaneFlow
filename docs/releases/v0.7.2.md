## What's new

PaneFlow 0.7.2 is a fix release. Clicks, review, agent hooks, and session restore are more reliable.

## Fixed

- A click selects the cell under the pointer, including a click on the boundary between cells. A click with no drag no longer opens a link when the selection read fails.
- An oversized grapheme in terminal output no longer fails the pane snapshot or stops the child process. The block cursor stays readable against the pane background.
- Hovering a path while scrollback is showing reads that line, and the lookup stays off the UI thread.
- Terminal input that stalls stays inside the write queue instead of blocking the runtime.
- Review of a checkout in another repository uses that repository. A symlink is sized by the link. Copy-hunk headers stay aligned when a neighbour is close, and the diff branch chip opens from the keyboard.
- Returning a pane to the workspace root restores that workspace's git watch. Untracked files are counted without following non-regular files, and a burst of file events does not stall the watcher.
- Review prompts do not execute branch names. Managed git commands ignore local aliases.
- Queued-prompt chips and broadcast membership stay correct for panes on background tabs. An idle shell takes its name from the foreground process.
- Shortcut recording disarms when settings reload. Menu actions still run while the window is minimized. Opening a folder that is already open still selects that workspace when the list is at its cap.
- Undo-close stops at the pane cap. Each toast animates on its own. A clicked file uses the macOS handler when the only configured editor is a terminal program.
- Review cost for Opus 4.5 and later, including Opus 5 and 5.5, uses the later rate. Opus 4 and 4.1 stay on the previous rate. A Pi session survives a long line split across a UTF-8 boundary. A stale PaneFlow Pi extension is repaired, and the OpenCode plugin is stored as an absolute path.
- Agent hooks resolve on PATH. Before each wrapped launch, PaneFlow removes project hook commands whose binary is gone. MCP install merges the backup taken before the CLI rewrite and refuses a Codex environment that widens PaneFlow's scope. A fresh OpenCode install creates `opencode.json`.
- Session restore writes the restored session before it returns, publishes it when staging finishes, and does not follow a symlink planted at the temporary session path.
- Quitting updates a symlinked window-state file in place instead of replacing the link with a regular file. Home-directory redaction in crash reports stops at a line break.

## Install

Download the `.dmg`, open it, drag PaneFlow to `/Applications`.
Requires macOS on Apple Silicon.
