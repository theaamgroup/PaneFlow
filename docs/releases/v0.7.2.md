## What's new

PaneFlow 0.7.2 is a fix release. Clicks, review, agent hooks, and session restore are more reliable.

## Fixed

- A click selects the cell under the pointer, including a click on the boundary between cells. A click with no drag opens its link without waiting on a selection read, and a failed selection read does not open a link.
- An oversized grapheme in terminal output no longer fails the pane snapshot or stops the child process. The block cursor glyph stays readable against the cursor when the cell and layout backgrounds are transparent.
- Hovering a path while scrollback is showing reads that line, and the lookup stays off the UI thread. Switching mouse-tracking mode, including X10, URXVT, and SGR-pixels, updates the click report format.
- A directory name outside ASCII is reported as its real path. Spawning a pane replaces the shared shell-integration scripts only after the new file is complete, so a shell starting during that write still runs the user's startup.
- Terminal input that stalls stays inside the write queue instead of blocking the runtime. Startup adopts the login `PATH` when a profile background job holds the capture pipe open.
- A dead network mount no longer freezes launch or the session menu. Those directory checks give up after a short bound.
- Review of a checkout in another repository uses that repository. A symlink is sized by the link. A failed `HEAD` lookup shows an error instead of an empty diff. Copy-hunk headers stay aligned when a neighbour is close, and the diff branch chip opens from the keyboard.
- Returning a pane to the workspace root restores that workspace's git watch. Untracked line counts skip non-regular files, and a burst of file events no longer stalls the window.
- Review prompts do not execute branch names. Managed git commands ignore local aliases.
- Queued-prompt chips and broadcast membership stay correct for panes on background tabs. An idle shell takes its name from the foreground process. A service chip stays on the anchor's loopback port.
- Shortcut recording disarms when settings reload. Menu actions still run while the window is minimized. Dropping or reopening a folder that is already open selects it when the workspace list is full.
- Undo-close stops at the pane cap. Each toast animates on its own. A clicked file uses the macOS handler when no editor is configured, instead of launching the vim that ships with macOS.
- Review cost for Opus 4.5 through 4.8 and Opus 5 uses the $5/$25 rate. Opus 5.5 uses $4/$20. Opus 4 and 4.1 stay at $15/$75. Haiku 4 uses the $1/$5 rate. A Pi session survives a long line split across a UTF-8 boundary. A stale PaneFlow Pi extension is repaired. The OpenCode plugin is stored as an absolute path, and a symlinked plugin file is left unchanged.
- A bare hook name counts as installed only when it is on `PATH`. Before each wrapped launch, PaneFlow removes project hook commands whose binary is gone. If an agent's MCP rewrite does not verify, install merges the config from before that rewrite. Codex environment keys that pin PaneFlow's scope or pane identity are removed. A fresh OpenCode install creates `opencode.json`.
- Session restore writes the restored session before it returns, publishes it when staging finishes, and does not follow a symlink planted at the temporary session path.
- Quitting updates a symlinked window-state file in place and leaves a dangling link alone. Home-directory redaction in crash reports stops at a line break, including on stack frames and debug images.

## Install

Download the `.dmg`, open it, drag PaneFlow to `/Applications`.
Requires macOS on Apple Silicon.
