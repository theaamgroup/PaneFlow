## What's new

- **See what every agent is doing on one chord:** `Cmd+Shift+I` lists every agent pane across every workspace with a one-line description of what it is doing or waiting on; the arrows select a row and Enter jumps to that pane. Summaries are generated on your Mac by Apple's on-device foundation model, so no terminal output leaves the machine, there is no API key, and no per-summary cost. It needs Apple Intelligence on macOS 26 or later; without it the overlay says so and nothing else changes. Turn the surface off with `"agent_summary_enabled": false`.
- **A command palette:** `Cmd+Shift+O` lists every action that works from anywhere - splits, tabs, workspaces, layouts, the overlays - each with the binding it currently answers to, including your own overrides. Type to filter on words in any order, move with the arrows, Enter to run.
- **Clone a repository from inside PaneFlow:** Clone repository takes a URL or a GitHub `owner/name`, or lists the repositories your signed-in `gh` account can see. Pick a folder, watch git's phase, percentage, and transfer rate, and the clone opens as a new workspace. GitHub targets go through `gh repo clone`, so private repositories and a fork's `upstream` remote work; everything else clones with git.
- **Recent folders:** PaneFlow remembers the last eight folders you opened as workspaces. With no workspace open, the sidebar lists them under Open recent, and `Cmd+1` to `Cmd+5` open the first five. Folders that no longer exist drop off the list.
- **Faster launch:** the 900 ms startup splash is gone. The window opens straight into the restored session or the empty state.
- **A notice when you upgrade:** the first launch of a newer version shows one "Updated to PaneFlow x.y.z" notice with a View release notes button. It stays until you dismiss it, and shows once.
- **Two more agent launchers:** DeepSeek Harness (`dsh`) and Muse Code (`muse`), both with live sidebar state - prompt, tool use, waiting, done - like the other hooked agents. Their buttons are off by default; turn them on in Settings → AI Agent.
- **Up to 32 workspaces**, raised from 20, matching the per-workspace tab and pane limits.
- Working out which agent CLIs are installed no longer blocks the window on first use. The Launch Pad and the New pane picker say they are looking until the scan lands.

## Fixed

- **Closing an overlay returns you to the pane you opened it from.** The theme picker, broadcast picker, fleet search, Launch Pad, Pane Overview, Attention Queue, the New pane picker, and the agent summary all used to land on the first pane of the tab.
- Opening a New pane tab no longer fails when the workspace's new-tab branch is missing: it reports git's reason and opens the picker on the workspace checkout.
- Creating a workspace at the limit says so. `Cmd+Shift+N`, Window ▸ New Workspace, and Open folder all used to read as dead gestures.
- The empty-workspace screen names the entry points that exist - `Cmd+Shift+N`, Window ▸ New Workspace, and the sidebar's Open folder - instead of a sidebar `+` that was removed two releases ago.
- A second PaneFlow instance shares the DeepSeek Harness and Grok hook files instead of refusing them, so both instances report agent state.

## Install

Download the `.dmg`, open it, drag PaneFlow to `/Applications`.
Requires macOS on Apple Silicon.
