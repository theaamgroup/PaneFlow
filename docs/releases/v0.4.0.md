## What's new

- **Work Review — Cmd+Shift+U:** See open tasks, PR checks, and overlapping worktree changes together.
- **Start from an issue — Cmd+Shift+L:** Turn a GitHub issue into an editable task and branch.
- **Richer agent handoffs:** Carry the current revision and changed files into your next agent session.
- **Branch labels per terminal:** Keep the right checkout visible as you move between projects.
- **Update controls:** Check for updates from the app menu, see update status, and install on normal quit.

## Also new in v0.3.0

- **Pane Overview:** See every open pane grouped by workspace and tab, then jump straight to one.
- **Worktree tabs:** Pick a branch when opening a tab and keep each tab in its own checkout.
- **Worktree removal:** Remove a PaneFlow-created worktree from its tab's menu when you're done with it.
- **Session search:** Find previous agent sessions by summary or session ID.
- **Session handoffs:** Copy a session summary or continue in another agent with an editable handoff prompt.
- **Agent setup:** Browse your workspace's instructions, skills, rules, hooks, and MCP setup in one place.
- **Sidebar customization:** Choose which details to show, expand or collapse all workspaces, and keep your fold preferences across restarts.
- **Pull-request markers:** Show each branch's PR status in the sidebar using GitHub CLI.
- **Accessible buttons:** Identify icon-only controls through tooltips and screen-reader labels.
- **Synchronized terminal output:** Let supported terminal apps present complete redraws together.
