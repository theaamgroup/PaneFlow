## What's new

- **Review mode:** Open several diffs side by side as independent panes, with a Workspaces rail and a Changes rail to pick subjects, and launch an agent on any subject straight from its pane header. (Cmd+Shift+G)
- **Editor gutter markers, revert, and minimap:** See added, changed, and removed blocks in the gutter, revert a block from its chip, and move through long files with a minimap.
- **Syntax highlighting for 15 languages** in the Changes dock editor.
- **Changes dock scrollbar:** A permanent editor-style scrollbar on the dock, so a long file's position is always visible.
- **Sharper terminal text:** The cell grid is now measured from the font itself, box drawing, shades, braille, and Powerline glyphs are drawn by the renderer, and underlines and cursors are sized from the font's own metrics.
- **Nerd Font icons at their designed size:** Icons keep their proportions instead of being squeezed into one cell.
- **Compact Pane Overview:** Every pane grouped into workspace grids, with split-pane labels and live previews.
- **MCP bridge nudge:** A sidebar prompt to install the PaneFlow MCP bridge for the agent that is actually running.
- **Agent context and task reporting:** Agents carry their pane identity, and session rows follow a pane when it moves.
- **Mark as read:** Clear a stale waiting badge from a tab's sidebar menu.
- **Unsaved work is protected:** Quitting or closing a tab with unsaved editor changes asks first.
- **Fewer wasted frames:** Idle terminal panes are cached, so a busy window spends less time redrawing panes that have not changed.
