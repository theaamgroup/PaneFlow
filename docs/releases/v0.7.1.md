## What's new

- **Files open in your editor.** Clicking a path in the terminal, including Markdown, opens it in the editor chosen in Settings. There is no in-app file browser, code editor, or rendered Markdown page. Git diff and Review are unchanged, and Review still highlights Markdown.
- **One way to open the workspace.** `Ctrl+Alt+Z` launches the editor from Settings. The separate Zed, Cursor, VS Code, and Windsurf commands are gone.
- **Jump to whoever is waiting.** `Cmd+Shift+J` moves to the next agent that is waiting on you, including one in a background tab. Sidebar status marks and notifications stay.
- Settings files and saved sessions that still mention a removed surface keep loading.

## Removed

- The fleet summary on `Cmd+Shift+I`, and the on-device model sidecar that produced it. Sidebar status marks and Pane Overview stay.
- The Launch Pad on `Cmd+Shift+L`. New panes and agents still start from the new-pane picker.
- The Clone repository modal. Clone in a terminal, then open the folder. Recent folders stay.
- The title-bar avatar and its menu. Settings and About stay on the PaneFlow menu. Themes stay in Settings → Appearance.
- Fleet search (`Alt+F`) and its pane badges. Find in the focused pane, and search through MCP, stay.
- The Attention Queue overlay. Waiting navigation is `Cmd+Shift+J`.
- The sidebar pull-request icon. The branch name stays.
- The workspace template builder in Settings, and per-workspace custom buttons. PaneFlow still restores the workspaces you had open. `Cmd+Shift+U` is still Work Review.
- CLI verbs `up`, `new`, `select`, `split`, and `focus`, and the CLI event stream. Read and send remain. Workspaces and panes are still managed in the app.

## Fixed

- A clicked file uses the editor configured in Settings, ahead of environment and PATH fallbacks. System mode uses the macOS file handler.
- Branch names stop refreshing while the sidebar or the branch line is hidden, and resume on the two-second tick when you show them again.

## Install

Download the `.dmg`, open it, drag PaneFlow to `/Applications`.
Requires macOS on Apple Silicon.
