## What's new

PaneFlow 0.8.0 removes the MCP bridge and several little-used surfaces, adds a running-agent count and keyboard pane resizing, and fixes a long list of terminal, review, agent-hook, and session issues.

## Breaking changes

PaneFlow no longer ships its MCP bridge, `paneflow-mcp`. The **MCP
Servers** Settings page, the sidebar "Install MCP bridge" callout, and the
`paneflow mcp` verb are gone. `paneflow mcp` now exits with the
unknown-verb usage error (exit code `2`). Agents and scripts read panes
through the JSON-RPC socket (`surface.read`, `surface.search`,
`agent.whoami`), documented in the
[scripting reference](../user/scripting/reference.md). A leftover
`mcp_bridge_prompt_dismissed` key in `paneflow.json` is ignored.

On first launch, PaneFlow removes the `paneflow` MCP entry it wrote to
Claude Code, Codex, Gemini CLI, and opencode. It removes only a `paneflow`
entry whose command is a `paneflow-mcp` binary, at any path. A `paneflow`
entry that runs anything else is left alone. Before changing a file it saves a
backup next to it: `<file>.bak` if that name is free, otherwise
`<file>.paneflow-bak`, then `<file>.paneflow-bak.1`, `.2`, and so on. It never
overwrites an existing file. The next launch checks again and, when it finds
no entry, deletes the extracted binary at
`~/Library/Application Support/paneflow/bin/paneflow-mcp`. If an entry cannot
be removed, PaneFlow keeps the binary so the entry keeps working, and retries
on the next launch.

The cleanup always checks each agent's default config location. It also checks
the locations named by the environment PaneFlow was launched with, and by the
`CLAUDE_CONFIG_DIR`, `CODEX_HOME`, `OPENCODE_CONFIG`, `OPENCODE_CONFIG_DIR`,
and `XDG_CONFIG_HOME` values your login shell sets. It reads those login-shell
values only on a Dock or Finder launch with launchd's default `PATH`. After
`open --env PATH=…` or `launchctl setenv PATH …` it does not. A launch from a
terminal already has them, and a relative value is ignored. An entry in a
location it cannot see has to be removed by hand:

- Claude Code: `claude mcp remove -s user paneflow`
- Codex: `codex mcp remove paneflow`, or delete the
  `[mcp_servers.paneflow]` table from `~/.codex/config.toml`
  (`$CODEX_HOME/config.toml` when `CODEX_HOME` is set)
- Gemini CLI: delete `mcpServers.paneflow` from `~/.gemini/settings.json`
- opencode: delete `mcp.paneflow` from `opencode.jsonc` or `opencode.json`
  in `~/.config/opencode/` (`$XDG_CONFIG_HOME/opencode/` when
  `XDG_CONFIG_HOME` is set), and from the file `OPENCODE_CONFIG` names or the
  one in `OPENCODE_CONFIG_DIR` if you set either

The CLI read verbs `paneflow ls`, `read`, `search`, `ps`, `status`, and
`whoami`, and their hidden aliases `list_panes`, `read_pane`, and
`search_pane`, have been removed. They exit with the unknown-verb error and do
not start the app. Every JSON-RPC method stays, so scripts read panes through
the socket instead. `paneflow send`, `paneflow key`, and `paneflow hooks` are
unchanged.

Pane task assignment has been removed: the `paneflow task` verb and the
`task.get`, `task.assign`, and `task.report` JSON-RPC methods, which now return
method-not-found errors. Saved sessions that carry task data still load and
keep each pane's identity.

## Added

- Each workspace row in the sidebar shows how many agents are running there (thinking, waiting for input, or stalled) plus the subagents they run. The count hides at zero. Claude Code, Codex, Cursor, and Grok report subagents through their hooks, and OpenCode reports child sessions. A subagent finishing no longer marks its parent's turn finished.
- Resize the focused pane from the keyboard. `Cmd+Ctrl+Right` and `Cmd+Ctrl+Left` grow and shrink its width, and `Cmd+Ctrl+Down` and `Cmd+Ctrl+Up` grow and shrink its height. A neighbour never shrinks below the minimum pane size.

## Changed

- Pasting several lines into a program that has bracketed paste off is refused with a message, because each line would run as a command. A single line still pastes, and a program that uses bracketed paste still receives the line breaks.
- A program in a pane can post at most one desktop banner every four seconds, and an identical repeat is dropped. Other panes can still notify.
- Repeated toasts are dropped, and only a few different messages wait their turn. Copying several times no longer replays "Copied" for seconds.
- Hermes started from PaneFlow no longer runs with every hook pre-approved. PaneFlow adds only its own hook commands to Hermes's `shell-hooks-allowlist.json` and removes them when the last Hermes session exits. A crashed session's approvals are removed on the next launch. The user's own approvals are left alone.
- Crash reporting stays off when `paneflow.json` cannot be read or its switch is anything other than `true`. A missing file or a missing switch still reports crashes as before.
- Gemini sessions are listed newest first, and their rows no longer show a relative age.

## Removed

- The command palette on `Cmd+Shift+O`. Every action it listed has its own shortcut, and Settings → Keyboard Shortcuts lists them all. Pane Overview and the new-pane picker stay.
- The keyboard pane-swap mode on `Cmd+Shift+S`. Drag one pane's header onto another pane to swap them.
- The Changes dock, the right-hand panel opened from a pane header, with its terminals and its Agent setup tab. `Cmd+Shift+F` and `Cmd+J` no longer do anything. Review and Work Review still show diffs.
- The Composer prompt box (`Cmd+Shift+Space`) and its queued prompts, and broadcast groups (`Cmd+Shift+B`, `Cmd+Shift+M`). `paneflow send`, including `--broadcast`, stays.
- The right-click menu on a Sessions sidebar row (Continue in, Copy summary, Resume). Click, Enter, or Space still resumes a session, and dragging it onto a pane still works.
- Recent folders. The empty sidebar shows only Open folder, and `Cmd+1` to `Cmd+5` do nothing until a workspace is open. An existing `recents.json` is left on disk and ignored.
- The cost estimate and token totals in Review's attribution hover. The hover still lists the credited sessions, with each agent and when it ran.
- The bundled Lilex and IBM Plex Sans fonts, which makes the app about 1.6 MB smaller. A setting that names either falls back to the default font unless it is installed on the Mac.
- The Injection fence switch in Settings → General. The fence is always on.
- The `new_tabs_on_main` setting. New tabs follow `new_tab_branch`; set it to an empty string to use the workspace checkout.
- Automatic removal of checkouts an older build created for a workspace. Closing a workspace never removes a checkout. To remove an old one, delete its `.paneflow-worktree` file and use **Remove worktree**, or run `git worktree remove --force <path>`.
- Settings files and saved sessions that still mention a removed feature keep loading. A shortcut bound to a removed action is skipped.

## Accessibility

- VoiceOver announces the pane rename field, an agent's failed or waiting status dot, the zoom badge, and copy mode. The COPY badge follows the theme accent.
- In Settings, the open section is announced as selected, and the font picker keeps the chosen font as its name while you filter. The cursor color and shortcut rows have names and open from the keyboard, and a fixed shortcut is marked disabled.
- The Review-with-agent menu uses checkboxes and a named launch button, works from the keyboard, and closes with Escape.
- Pane header hovers settle instantly when Reduce motion is on. Input methods such as Japanese and Chinese find the character under the pointer in text fields.

## Fixed

- A pane no longer dies when a program floods it with bells, notifications, clipboard copies, or unknown escape sequences, including a long paste into a program that is not reading input. The extras are dropped, and the newest notification and clipboard copy are kept.
- `Cmd+K` waits for a color sequence in progress to finish before it clears, so no stray letters are left behind. Selected text stays readable on the light themes and Cursor Dark. A program that asked to hear about light and dark changes is told when the theme switches.
- Searching a pane while it prints no longer attaches a hit to the wrong line or reports a partial scan as complete. `surface.search` returns an error when a newer search replaces it. `surface.read` and `surface.search` trim their replies to fit and mark them truncated, and any reply that still does not fit becomes a readable error.
- A script request with a wrongly typed field is refused and writes nothing. A `surface_id` that is not a whole number no longer targets the active pane, and wrong types for `text`, `submit`, `paste`, `keystroke`, or `name` are errors. With AI free access on, every keystroke and text write is logged.
- A hook that sends a status update and hangs up at once is no longer dropped, so the sidebar sees every prompt, tool, and stop event. A finished turn is not erased by the timer of an earlier one. A session ending for an unknown process no longer removes another agent's row.
- Clicking a workspace, `Cmd+1` to `Cmd+9`, Pane Overview, and Jump Next Waiting reveal a pane hidden by zoom before focusing it.
- Showing a diff no longer runs a repository's text-conversion or clean-filter commands. Review no longer rewrites the git index on refresh, so `git add` and commit are not blocked by a locked index.
- A diff copied from Review matches what git prints: a renamed file keeps its old name, a large text file is not called binary, paths with special characters are quoted, and the "more files" row copies nothing. A lone carriage return stays inside its line, and a deleted file with an untracked copy shows its own counts.
- Review notices edits after a branch diff grows past 16 MiB, refreshes for a checkout under a `target` or `node_modules` folder and for new top-level folders, and does not re-run attribution when nothing changed. Switching split and unified view during a reload shows the new lines. A saved Review grid survives a restart with Review off, and a restored Review pane keeps its workspace.
- Work Review checks each repository once, and a checkout with thousands of untracked files stays open with its count marked incomplete.
- Removing a checkout no longer erases another worktree whose folder is temporarily missing. A failed `.env` copy leaves no partial file. A folder name that is not valid text is refused with a message instead of being saved damaged.
- The branch picker shows the real name when a tag shares it, and a reftable repository shows its branch instead of `.invalid`. A slow checkout that lands after a newer choice no longer rebinds the tab, and a late directory lookup no longer rebinds a tab the pane has left. An undone pane starts inside the active tab's worktree.
- A dead network drive no longer stalls launch: each saved folder is checked once with a shared quarter-second budget, and a folder that cannot be checked in time keeps its saved path. The installed-agent scan gives up on a stuck `PATH` folder after a quarter second, and a split in a bound tab no longer asks the disk when its path already matches.
- Clicking a web link and toggling a sidebar row no longer freeze the window. Idle panes scan the process table every five seconds instead of twice a second. The port chip finds listeners in a process with more than 1024 open files.
- Starting PaneFlow inside another PaneFlow and then launching Claude or Codex no longer spawns copies until the Mac runs out of processes. The launcher skips a program you are not allowed to run.
- Enabling Codex hooks recognizes every way a config can already spell its features, instead of adding a second `[features]` section. Hermes install refuses a config that already has hooks in any YAML spelling. Gemini hooks install into a settings file with comments and keep them. A deeply nested settings file is rejected instead of crashing the helper.
- Ending a session does not write through a project hook file that became a symlink. Hook logs are written only to a regular file at a full path, and hook cleanup failures are logged. Stale lock files from older builds are cleaned up on launch.
- The Sessions sidebar keeps a Claude or Codex session whose long line splits a character, leaves out Hermes sessions from similarly named sibling folders, and reuses a scan that is already running.
- An oversized session file is moved aside instead of being overwritten, a corruption backup is readable only by you, and a session written by a newer build no longer looks corrupt. Undo-close keeps a pane's newest output, and it closes an open tab menu first. An inline rename lands on the row you started editing.
- A symlinked `paneflow.json` reloads when edited, including one replaced by a symlink after launch. Keys PaneFlow owns in `terminal.env`, such as `ZDOTDIR`, are logged when dropped and documented.
- In Settings, Escape closes the theme menu before the window, Enter picks the matching font, the scheme chip uses the theme accent, and shortcut labels show the minus key. The stale Theme picker rows are gone from the shortcut list. A failed desktop notification is logged.

## Install

Download the `.dmg`, open it, drag PaneFlow to `/Applications`.
Requires macOS on Apple Silicon.
